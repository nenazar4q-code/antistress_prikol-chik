# ZenFlow — Антистрес Простір

Інтерактивний антистрес вебзастосунок на React + Vite.

## Вкладки
- 🫧 **Бульбашки** — лопай бульбашкову плівку
- 💥 **Вдарити!** — великий rage button з частинками
- 🌊 **Хвилі** — клікай і спостерігай хвилі
- 🫁 **Дихання** — техніка 4-4-6-2
- 🥁 **Барабани** — барабанні паді
- 🎊 **Феєрверк** — canvas-анімація конфеті

## Запуск локально
```bash
npm install
npm run dev
```

## Деплой на Cloudflare Pages
- **Build command:** `npm run build`
- **Output directory:** `dist`

## Структура файлів
```
src/
  App.jsx      ← головний компонент з усіма віджетами
  App.css      ← стилі
  index.css    ← базові стилі
  main.jsx     ← точка входу
index.html
vite.config.js
package.json
```
